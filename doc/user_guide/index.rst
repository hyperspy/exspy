##########
User Guide
##########

**eXSpy** extends HyperSpy with tools for the analysis of multi-dimensional
Energy Dispersive X-ray Spectroscopy (EDS), Electron Energy Loss Spectroscopy
(EELS) and Secondary Ion Mass Spectrometry (SIMS) data. The chapters below
document the tools specific to each of these signals.
