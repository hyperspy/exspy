``exspy.data.eelsdb`` uses version 2 of the EELS Data Base API and loads the HSPY file of each spectrum, so all spectra load, with their DOI, when they have one, in ``metadata.General.doi``. Gas-phase spectra are included, and the new ``phase`` argument selects by specimen phase. ``original_metadata.json`` now holds the API v2 record, unsupported ``order`` keys are ignored with a warning, and the ``min_energy_compare``, ``max_energy_compare`` and ``resolution_compare`` arguments are deprecated: only their defaults are supported. Passing ``resolution`` as a string such as ``"0.7 eV"`` is deprecated, and invalid argument values raise a ``ValueError`` with the message from the database.
